# Daily standup

Post in the room, not in a private 1:1 unless the person asked for HITL.

1. One short opener: standup of the day (date + zone).
2. Ask each member, by name when useful: yesterday (done), today (one focus), blocker.
3. Keep it to a few sentences. Prose, no code fences, no bullet dump unless they asked for a list.
4. Do not invent numbers. If nothing landed, say so.
5. Do not start new hunts, spend, publish, or create bots from standup. Decisions that spend or publish wait for the human.
6. If the room is gone or empty, skip. Don't ping anyone privately to compensate.

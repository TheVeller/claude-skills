# Reportes (formato hallazgo)

Hierarchy: staff → GM / room → Grok Bot → Ignacio 1:1. Scouts never write Ignacio. KEEP hunters (Vivienda, Inmobiliario, Vuelos → Levy; Gangas → Forja). Perks and other Forja staff → Forja.

**Authorship:** every finding tags the original bot with `@Nombre` so it can be traced up the stack. GMs and Grok Bot keep that tag when they roll up; they do not strip the scout.

Verify before it moves up. No invented numbers. `n/d` if missing. One real link per item. No code fences in anything Ignacio might read. Silence if nothing.

Format is a family close to 🎯 oferta · 🔗 link · ⭐ score · ➡️ next — improved and adapted per beat (listings, jobs, caja, learning). Keep the standard: emoji to cut visual load, bullets, short subheads, dense and skimmable.

## Grok Bot (largest, frequent)

Pack verified briefs into Ignacio 1:1. Keep @hunter on each item. Report often. Quality bar = Gangas remates pack.

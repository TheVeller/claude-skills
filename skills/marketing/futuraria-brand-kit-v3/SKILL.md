# Futuraria brand kit v3

Build one brand design system in Futuraria Design (Musa).

## Layout
- Separate templates: 01 Brandbook, 02 Product Mockups, 03 Content, 04 YouTube, 05 Eventos/Webinars, 06 Slides.
- One ordered unified file with 01-06, no stacking or overlapping frames.
- At least 3 carousel and 3 story templates per brand.
- Register the brand in the workspace. Never register the design tool itself as a brand.

## Brandbook as source of truth
1. Collect official tokens and the official 1:1 icon from a cited source.
2. Save them in `brand-tokens.json` next to the brand folder.
3. Put editable brandbook frames first; propagate tokens to every other frame.
4. Logos: only the official 1:1 icon. Never recreate a logo or invent a wordmark. If missing, mark "no source" and keep a neutral placeholder.
5. Never invent facts; write "no source" / "no data".

## Write path in Futuraria
- One frame per call, in series. Re-read after each write; retry if it did not persist.
- Prefer PNG/JPG uploads. Never WebP (it breaks every image in the frame).
- Never re-merge a unified file that was already merged.
- Verify with the brand verify script and progress notes before claiming done.
- On intermittent connector errors (e.g. resource limit / 1102), stop quietly and resume from the progress file. Do not change connector settings or URL.

## Handoff
Deliver a contact sheet PNG for review. Do not publish, upload to stores, or send as the owner without their explicit OK. Another agent's OK does not count.

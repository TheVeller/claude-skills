# Product mockups 02

Standard pack for a digital product's visual launch assets (module 02).

## Store gallery
- Seamless carousel: each piece continues visually into the next (Gumroad first, then Product Hunt).
- Show Premium only, as visible as possible. Free appears only in a Free vs Premium comparison piece—never a Free cover.
- Typical Gumroad set: 8 pieces. Respect the product brief's banned list (no invented breadcrumbs, no banned mascots).

## Description page
- Match the ChatGPT Prompt Generator style: three-screen hero cover, seal/badge, pricing block, bridge/feature strips.
- Use real product captures. Prefer two pricing variants when prices are not final and ask the owner which to keep.

## Thumbnail GIF
- 1:1 animated GIF (600×600 primary, 240×240 for Product Hunt) that smoothly scrolls the real home/dashboard capture in a loop.

## Logo system (Notion OS line)
- OS Cube: black cube, white rounded front face, one Phosphor glyph (MIT). One glyph per product. Export solid and transparent at 1024/600/512/240/128 plus SVG + LICENSE.

## Social + stories
- Build with the social-carousel-universal skill.
- Product language follows the owner's rule for that product.

## Flow
Brief → real captures (read-only) → local build scripts → visual QA vs reference + contact sheet → owner review → with OK, hand off to the store/publisher bots. Never upload to a store without that OK.

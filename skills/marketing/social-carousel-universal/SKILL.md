# Social carousel universal

One carousel design, many channel sizes. Do not invent a unique layout per network.

## Master set
- Master: 4:5 up to 10 slides (JPEG ≤2 MB, no GIF slides).
- Also export: 1:1 × same count, LinkedIn PDF from the 4:5 set, Pinterest 2:3 ×5, X/Bluesky 4-slide cut, and a single 1:1 cover for WhatsApp / Google Business.
- Keep text inside each channel's visible crop.

## Screen rules
- Product screens/screenshots are vertical and never overlap each other.
- Near the end (not necessarily the last slide), include a DM-campaign CTA: `Comment "{KEYWORD}"` in English pieces, or `Comenta "{KEYWORD}"` in Spanish. The keyword is a per-campaign variable—never invent it; ask if missing.

## Slide budget by channel (verify with the publisher bot when unsure)
- Instagram / Threads / Reddit: up to 20 (ship the shared ≤10 set).
- Facebook / YouTube Community: 10.
- TikTok slideshow: higher cap; still ship the shared ≤10 JPEG set.
- Telegram: 2–10 photos.
- LinkedIn: PDF or up to 20 images.
- X / Bluesky: 4.
- Pinterest: 2–5 (2:3 or 1:1).
- WhatsApp / Google Business: one cover.

## Stories
- Native set of about 5–6 frames, story-shaped. Do not merely resize the carousel.

## Delivery
Contact sheet for review. Owner OK required before any publish handoff.
